Инструктаж по технике безопасности

Перед началом работы в лаборатории ознакомьтесь с правилами безопасности:

  • Всегда надевайте защитные очки и перчатки
  • Не пробуйте вещества на вкус
  • Не нюхайте вещества непосредственно из пробирки
  • Соблюдайте осторожность при работе с нагревательными приборами
  • Не оставляйте эксперименты без присмотра
  • В случае аварии немедленно сообщите преподавателю

Помните: В реальной лаборатории все эксперименты должны проводиться под руководством преподавателя!

Результат реакции

Примеры реакций

  1. KMnO₄ + H₂SO₄ + (CH₃)₂CHOH → 100°C → Гроза в колбе
  2. Zn + HCl → H₂↑ (получение водорода)
  3. AgNO₃ + NaCl → AgCl↓ (белый осадок)
  4. KSCN + FeCl₃ → [Fe(SCN)]²⁺ (кроваво-красный)
  5. CuSO₄·5H₂O → 100°C → CuSO₄ (белый) + 5H₂O
  6. Mg + O₂ → 150°C → MgO (горение магния)
  7. Na + H₂O₂ → Взрыв (бурная реакция)
